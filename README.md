# java-racingcar-precourse

---
## ✅️ 테스트 목록

- 입력
  - 자동차 수
    - 2대 이상
  - 자동차 이름
    - 앞뒤 공백을 제외하고 5글자 이하
    - 여러 단어 구성 허용 (ex. "car 1", "c a r")
    - 공백으로만 구성 불가 (ex. " ")
  - 시도할 횟수
    - 1회 이상
    - 숫자로만 입력
- 레이스 진행
  - 무작위 값이 4 이상일 경우 자동차 전진
  - 무작위 값이 3 이하일 경우 자동차 전진 x
- 출력
  - 차수별 실행 결과 눈금
  - 최종 우승자
    - 단독 우승
    - 공동 우승
    - 쉼표 구분
