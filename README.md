## 🚘 초간단 자동차 경주 게임기 사용설명서

- 2대 이상의 자동차 이름을 입력합니다.
  - 자동차 이름은 ,(쉼표)로 구분하고 5글자 이내여야 합니다.
- 이동을 시도할 횟수를 입력합니다.
- 레이싱 결과가 출력됩니다.

### 사용 예시
```
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
pobi,woni,jun
시도할 횟수는 몇 회인가요?
5

실행 결과
pobi : -
woni : 
jun : -

pobi : --
woni : -
jun : --

pobi : ---
woni : --
jun : ---

pobi : ----
woni : ---
jun : ----

pobi : -----
woni : ----
jun : -----

최종 우승자 : pobi, jun
```

## ✅️ 테스트 목록

- 입력
  - 자동차 수
    - 2대 이상
  - 자동차 이름
    - 앞뒤 공백을 제외하고 5글자 이하
    - 여러 단어 구성 허용 (ex. "car 1", "c a r")
    - 공백으로만 구성 불가 (ex. " ")
  - 시도할 횟수
    - 1회 이상
    - 숫자로만 입력
- 레이스 진행
  - 무작위 값이 4 이상일 경우 자동차 전진
  - 무작위 값이 3 이하일 경우 자동차 전진 x
- 출력
  - 차수별 실행 결과 눈금
  - 최종 우승자
    - 단독 우승
    - 공동 우승
    - 쉼표 구분
